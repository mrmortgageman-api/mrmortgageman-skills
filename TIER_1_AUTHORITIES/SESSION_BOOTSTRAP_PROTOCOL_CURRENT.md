# SESSION_BOOTSTRAP_PROTOCOL_CURRENT

**Version:** 2026-06-27  
**Status:** Operational Protocol  
**Purpose:** Every Applied Intelligence session begins from approved authorities, not reconstructed chat context.

---

## Core Rule

Thinking lives in conversations.  
Decisions live in institutional memory.  
Authorities live in version control.

---

## Required Startup Sequence

Every session follows this sequence before work begins:

### 1. Load Constitutional Layer
- APPLIED_INTELLIGENCE_PRINCIPLES_CURRENT
- APPLIED_INTELLIGENCE_GOVERNANCE_MODEL_CURRENT

### 2. Load Current Operating Configuration
- CURRENT_OPERATING_CONFIGURATION_CURRENT

### 3. Load Domain Authority
- The current review journal, doctrine, protocol, or project document relevant to the task
- Example: PRODUCT_REVIEW_JOURNAL, SIGNALSTRIKE_OPERATIONS_MANUAL, TCA_APEX_BRIEF

### 4. Confirm Decision Class
- Class A (Strategic / Architectural)
- Class B (Product / Workflow)
- Class C (Execution)

### 5. Begin Work
- Work from approved truth, not reconstructed chat context
- Reference authorities explicitly
- Decisions flow through governance model, not assumed from previous conversations

---

## Why This Matters

Without this sequence, sessions drift. Context gets rebuilt. Decisions get redebated. Authorities get lost.

With this sequence, every session starts from the same truth. Execution is faster. Decisions are cleaner. Institutional memory stays clean.
