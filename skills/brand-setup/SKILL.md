# Brand Setup — Interactive Brand Profiling

## When to Use This Skill

- User says "set up a new brand" or "create a brand profile"
- User mentions a new client or project for marketing
- User wants to switch between brands
- User wants to update brand voice, audiences, or goals
- First time using any marketing skill without an active brand

## Setup Modes

### Quick Setup (5 questions)
1. **Brand name**
2. **What you do** — one sentence
3. **Target audience**
4. **Brand voice** — pick 3 words
5. **Primary channel**

### Full Setup (17 questions)
Use when user explicitly asks for detailed/full/comprehensive setup.

Covers: Brand Identity, Business Model, Industry & Compliance, Brand Voice, Channels & Goals, Competitors.

## Important Notes

- NEVER skip the brand voice section
- For agencies: each client should be a separate brand profile
- Auto-detect industry compliance rules based on industry and market selections
