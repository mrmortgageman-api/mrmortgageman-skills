# /dm:campaign-plan

## Purpose

Generate a comprehensive multi-channel campaign plan ready for execution.

## Input Required

- **Campaign goal**
- **Product/service**
- **Target audience**
- **Budget**
- **Timeline**
- **Constraints**

## Process

1. Load brand context
2. Clarify campaign objective
3. Define audience segments
4. Recommend channel mix
5. Allocate budget
6. Build phased timeline
7. Define KPIs
8. Identify risks
9. Output full plan

## Output

- Campaign overview and SMART objectives
- Audience segments with targeting criteria
- Channel strategy with rationale
- Budget allocation table
- Phased timeline with milestones
- KPI dashboard framework
- Risk register
