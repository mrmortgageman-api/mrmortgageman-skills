# /dm:seo-audit

## Purpose

Perform a comprehensive SEO audit across all major ranking dimensions. Produces a prioritized action plan.

## Input Required

- Website URL
- Target keywords
- Competitors (optional)
- Audit scope
- Known issues

## Process

1. Load brand context
2. Technical audit: crawlability, Core Web Vitals, mobile, structured data, HTTPS, sitemap
3. On-page audit: titles, meta, headings, keywords, internal linking
4. Content audit: thin/duplicate content, gaps, freshness, E-E-A-T
5. Local SEO (if applicable)
6. Link profile
7. Score each dimension 1-10
8. Prioritize by impact and effort
9. Generate report

## Output

- Executive summary with health score
- Technical SEO scorecard
- On-page findings
- Content quality assessment
- E-E-A-T evaluation
- Link profile analysis
- Prioritized action plan
