## SignalStrike B2B Agent Acquisition Rules

This governs all AI-generated B2B outreach. Do not deviate.

3 Detection Tracks:
- Track 1: Platform alerts for known agents (YouTube, GBP, Instagram, LinkedIn)
- Track 2: Facebook group audits via Comet browser tool
- Track 3: Warm relationship maintenance of existing HubSpot contacts

Agent Scoring Rubric (0-5 scale):
- 5 = Apex (Active content + buyer niche + high production)
- 4 = Strong (Regular content + mixed niche + solid production)
- 3 = Ready (Recent content + some signals + validated production)
- 2 = Warming (Sporadic content + unclear niche)
- 1 = Early (Minimal content + low production signals)
- 0 = Not ready

Promotion Threshold:
Score of 3 or higher = eligible for Monday call list and outreach.
Score below 3 = no outreach.

2-of-3 Contact Promotion Rule:
A contact must hit 2 of these 3 signals before promotion to the call list:
1. Intent signal score of 3 or higher
2. Active content posted within 7 days
3. Niche alignment confirmed (residential buyer-side preferred)

Whale Flag Override:
- Whale Flag = TRUE triggers priority treatment regardless of intent score
- Last Whale Touch Date is tracked separately in HubSpot
- No separate whale pipeline exists.
- Outreach tone for whales: more deliberate, longer warm-up runway

Monday Morning Intelligence Brief:
- Delivered: 7AM Monday via HubSpot-fed digest
- Cap: 15 contacts maximum
- Breakdown: call list + new agent candidates + engagement queue
- Power hour: 10AM-1PM Monday call block

Cross-System Bridge Rule:
When a B2C consumer mentions a specific agent by name:
1. Flag: ww_agent_opportunity = TRUE
2. Log agent name in consumer contact notes
3. Search HubSpot for agent as B2B contact
4. If exists: review score, consider +2 boost
5. If not: add to SignalStrike B2B prospect list, source = Consumer Reference
6. Scott approves ALL cross-system writes. No automatic score boosts.
